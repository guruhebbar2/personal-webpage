# personal-webpage

Personal resume site. Plain HTML, CSS and JavaScript: no build step.

- `index.html`: all content (edit text here)
- `styles.css`: theme and layout (colors are variables at the top)
- `script.js`: circuit-trace background, typed roles, scroll effects

## Preview locally

Open `index.html` in a browser, or run `node .claude/serve.js` and visit http://localhost:8123.

## Host on GitHub Pages

Push to GitHub, then in the repository go to **Settings → Pages**, choose **Deploy from a branch**, and select `main` / root.
