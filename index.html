R1 · MR-ARFI

Real-time feedback for MR-HIFU histotripsy

Monitoring histotripsy with MR acoustic radiation force imaging. Displacement and PRFS temperature are measured from the same GRE-EPI phase images using alternating motion-encoding gradients, and the histotripsy pulse itself serves as the ARFI push.

  • Python processing pipeline from DICOM to displacement and temperature maps, focal curves and summary figures.
  • ARFI Studio: a desktop GUI to compare scans before and after therapy and replay a sonication the way a live system would see it.
  • Experiments in gel phantoms and ex vivo tissue across a range of acoustic powers.
  • Python
  • MR-ARFI
  • PRFS thermometry
  • GRE-EPI
  • GUI

R2 · THERAPY CONTROL

MRHIFU: MR-guided HIFU therapy software

A PyQt5 application for preclinical MR-guided HIFU on a Philips MRI with a Sonalleve system. It reads images live from the scanner, turns them into temperature and displacement maps, and steers the transducer.

  • Hyperthermia: live PRF thermometry with drift correction and model-predictive temperature control.
  • Histotripsy: a Setup → Planning → Therapy → Review workflow with MR-ARFI monitoring during pulsed sonications.
  • Python
  • PyQt5
  • PRF thermometry
  • MPC
  • Real-time

R3 · SIMULATION

arfisim: MR-ARFI simulation toolbox

Simulates the MR-ARFI experiments end to end in Python: acoustic field, radiation force, viscoelastic tissue displacement and MR motion encoding, ending in a synthetic scan that runs through the same processing pipeline as the real data.

  • Linear and nonlinear acoustics, heating and thermal dose, and finite samples.
  • Used to compare measured displacements with what the physics predicts.
  • Python
  • Acoustics
  • Viscoelastic model
  • Simulation
